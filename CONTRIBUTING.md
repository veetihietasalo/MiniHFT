# Contributing to MiniHFT

Thank you for your interest in contributing! This is an educational project focused on learning HFT concepts.

## How to Contribute

### 1. Code Contributions
- Additional quantitative models (Ornstein-Uhlenbeck, SABR volatility)
- Performance optimizations
- Cross-platform support (Linux/Mac)
- Additional benchmarks

### 2. Documentation
- Explanations of advanced concepts
- Tutorial videos or blog posts
- Code examples and use cases

### 3. Bug Reports
- Open an issue with reproduction steps
- Include system info (OS, compiler version)

## Development Setup

See [README.md](README.md) for build instructions.

## Code Style

- **C++ Standard**: C++20
- **Naming**: PascalCase for classes, camelCase for functions, UPPER_CASE for constants
- **Comments**: Explain "why", not "what"
- **Performance**: Prefer header-only, avoid heap allocations in hot paths

## Pull Request Process

1. Fork the repository
2. Create a feature branch
3. Add tests/benchmarks for your changes
4. Update documentation
5. Submit PR with clear description

## Questions?

Open an issue for discussion before major changes.
